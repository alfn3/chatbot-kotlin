📞 TROUBLESHOOTING QUICK HITS
────────────────────────────────────────────────────────────────────────────────
Fonts not loading?
  → Check app/src/main/res/font/ has TTF files
  → Use R.font.plus_jakarta_sans_regular (lowercase, hyphens)

Text not visible?
  → Check color contrast (use webaim.org/resources/contrastchecker/)
  → Aim for 4.5:1 ratio

Preview crashing?
  → Add @Preview annotation
  → Check for compilation errors
  → Rebuild project (Build > Rebuild)

Spacing looks off?
  → Use DimensionTokens from Dimensions.kt
  → All spacing should be multiples of 4dp
  → Double-check padding vs margin

Jank when scrolling?
  → Use LazyColumn instead of Column
  → Profile with Layout Inspector
  → Check for creating objects in composable body
